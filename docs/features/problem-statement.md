# Project: Hệ Thống Phiếu Bé Ngoan & Đổi Quà (Good Behavior Rewards App)

## 1. Problem (Vấn đề)
Các phụ huynh, thầy cô, hoặc quản lý nhóm muốn có một cách vui nhộn, trực quan và tích cực để khuyến khích trẻ em / thành viên hoàn thành nhiệm vụ hàng tuần. Việc quản lý bằng giấy hoặc lời nói dễ bị quên, thiếu hấp dẫn và khó theo dõi điểm thưởng tích lũy để đổi quà.

## 2. What I'm building (Sản phẩm là gì)
Ứng dụng Web / App quản lý và phát thưởng theo nền kinh tế **"Phiếu Bé Ngoan"**. Nơi người dùng (trẻ em / học sinh / thành viên) hoàn thành các nhiệm vụ hàng tuần hoặc nhập Gift Code để nhận các loại Phiếu Bé Ngoan độc đáo (với thiết kế hình ảnh/badge khác nhau cho từng loại). Sau đó dùng số phiếu/điểm tích lũy để đổi các phần quà trong Cửa Hàng Đổi Quà (Reward Store).

## 3. Must work - V1 (Tính năng bắt buộc phiên bản 1)
- [ ] **Hệ thống Phiếu Bé Ngoan với Visual riêng**: Thiết kế card/badge riêng biệt cho từng loại phiếu (ví dụ: *Bé Ngoan Chăm Học*, *Bé Ngoan Siêng Năng*, *Bé Ngoan Xuất Sắc*).
- [ ] **Weekly Tasks (Nhiệm vụ hàng tuần)**: Danh sách nhiệm vụ tuần, cho phép đánh dấu hoàn thành để nhận phiếu thưởng tương ứng.
- [ ] **Gift Code Redemption**: Ô nhập mã quà tặng (Gift Code) để quy đổi nhanh ra phiếu/điểm thưởng.
- [ ] **Ví Phiếu / Ví Điểm (User Inventory)**: Hiển thị bộ sưu tập các loại phiếu bé ngoan đã thu thập được và tổng điểm thưởng tích lũy.
- [ ] **Reward Store (Cửa hàng đổi quà)**: Danh sách phần quà với mức điểm quy đổi, cho phép đổi quà khi đủ điểm và trừ vào ví điểm.

## 4. Not doing yet (Chưa làm ở V1 - Để dành phiên bản sau)
- Hệ thống phân quyền nhiều lớp phức tạp (Phụ huynh/Thầy cô kiểm duyệt tác vụ trước khi nhận phiếu).
- Thanh toán / Mua Giftcode bằng tiền thật.
- Bảng xếp hạng (Leaderboard) toàn hệ thống.
- Thông báo Push notification.

## 5. Done means (Định nghĩa hoàn thành)
*"Tôi biết ứng dụng này hoạt động khi người dùng có thể nhận nhiệm vụ tuần hoặc nhập Gift Code để nhận Phiếu Bé Ngoan (hiển thị đẹp mắt đúng loại phiếu), tích điểm vào Ví và sử dụng điểm đó đổi được 1 món quà trong Cửa Hàng Đổi Quà."*
