# Workspace Guidelines - Phiếu Bé Ngoan & Đổi Quà

## Project Overview
This project is **Hệ Thống Phiếu Bé Ngoan & Đổi Quà (Good Behavior Rewards App)**. It is a web application designed for parents, teachers, or team managers to motivate children or group members to complete weekly tasks and redeem tickets/points for rewards in a Reward Store.

## Core Directives for Development
1. **Scope Scrutiny**: Focus on V1 core requirements (Visual Tickets, Weekly Tasks, Gift Codes, Ticket/Point Inventory, Reward Store). Keep features strictly within V1 scope.
2. **Design Quality**: Ensure high aesthetic quality with custom badge designs for ticket types, smooth transitions, and responsive layout.
3. **Data Persistence**: Use client-side storage (e.g., `localStorage`) for state management in V1.
4. **Preservation**: Do not delete or modify existing product documentation without explicit instructions.
